# 🧸 Spiffo Suit – More Colors (Build 41 Legacy)

**Spiffo gets a makeover!**  
This mod adds several fun color variations to the classic Spiffo Suit in Project Zomboid.

This is the **final release for Build 41**, preserved for multiplayer compatibility and servers that haven't upgraded to Build 42.

> ⚠️ Please do not reupload or include this mod in modpacks without permission from the creator.

---

## 🎨 Features

- Adds multiple new recolors of the Spiffo mascot costume
- Keeps the base game’s default suit intact
- Balanced for gameplay and just the right amount of ridiculous 🐻✨

---

## ✅ Compatibility

- ✔️ Compatible with **Project Zomboid Build 41**
- ❌ Not updated for Build 42 (which changes clothing behavior and outfit configs)

> A Build 42-compatible version will be maintained on the `main` branch of this repo.

---

## 💾 Manual Installation

1. Download the Build 41 release:  
   👉 [Release vB41.0](https://github.com/RHay6868/pz-mods-spiffo-suit-more-colors/releases/tag/vB41.0)  
   Or [Download ZIP directly](https://github.com/RHay6868/pz-mods-spiffo-suit-more-colors/archive/refs/tags/vB41.0.zip)

2. Extract the folder to your mods directory:  

C:\Users\YourUsername\Zomboid\mods\


3. Launch the game and enable the mod in the **Mods** menu
